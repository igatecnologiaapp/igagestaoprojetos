# IGA Tecnologia — Sistema de Gestão de Projetos

Gestão de projetos de software da IGA Tecnologia: pasta digital por projeto, tarefas e prazos, documentos,
ferramentas e contas, custos fixos e por consumo, receitas, resultado em **Superávit/Déficit**, Painel do
Gestor e Portal do Cliente.

```bash
bun install
cp .env.example .env   # dados do Supabase de homologação
bun run dev            # http://localhost:8080
```
